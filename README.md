# Polyadic Shell

An "incremental" introduction to a story of ancient intrigue and the revival of a long-dead colonial supply chain

## Demonstration link
https://youtu.be/c1rU5FFtZmc

## Additional information
### Obstacles
- I'd never made a game before
- I didn't know how games function
- I didn't know how to use pygame or pygame_gui
- I didn't know the underlying logic of a game's main loop and the way that frames are done and events are timed
### Triumphs
- By examing the documentation for the python libraries I used, I was able to learn their functionality and standard conventions, implement them in the design of my game, and begin to use and reuse them for my own unique designs
- I learned how github, version control, visual studio code, and git work
- I learned about file structure
### Summary
Overall, I greatly enjoyed the creation of my project. I found the strife in learning pygame and pygame_gui not only entertaining, but enriching. I learned a lot about the mechanics of python itself, the fundamental idea behind OOP, the way libraries work, the way programming projects are managed, and the way scope must be controlled. It paid off, because I ended up achieving my vision for the game and creating something that I feel proud of, especially considering the difficulties that it took to get there.
