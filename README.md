# Polyadic Shell

An "incremental" introduction to a story of ancient intrigue and the revival of a long-dead colonial supply chain

## Download Python and run the game

Prerequisites
- Python (>Python 3.10 preferably)

1) Install Python
- https://www.python.org/downloads/

2) Open command line/terminal and point at the game's location
- `cd (Path to game folder here)`

2) Install dependencies
- `pip install --upgrade pip`
- `pip install -r requirements.txt`

3) Run the game
- `python3 main.py`
